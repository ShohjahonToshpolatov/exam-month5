# TopFind frontend

Angular 20 asosidagi frontend. Backendni 3000-portda ishga tushiring, so'ng `npm start` orqali http://localhost:4200 sahifasini oching.

- `npm test`: TypeScript va Angular shablonlarini tekshiradi.
- `npm run build`: production build yaratadi.
- `/api` va `/uploads`: lokal proksi orqali backendga ulanadi.

Auth, e'lonlar, rasmlar, da'volar, profil, kategoriya va admin foydalanuvchilar boshqaruvi ulangan. To'liq sozlash va brauzer testlari uchun loyiha ildizidagi README.md fayliga qarang.
