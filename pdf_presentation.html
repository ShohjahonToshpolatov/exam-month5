2-BO'LIM // TEXNOLOGIYALAR

Full-Stack Texnologiyalar Steki

🔵

Frontend (Angular 19)

Standalone Components, Signals & RxJS. Modern Pure CSS3, 3D Perspective Transforms (`rotateX/Y/Z`), Glassmorphic UI va to'liq responsive layout.

🟢

Backend (Node.js)

Express.js Framework. RESTful API arxitekturasi, JWT Auth middleware, Multer fayl yuklagich va Nodemailer OTP email xizmati.

🐘

Database (PostgreSQL)

PostgreSQL Relational DB. Yuqori tezlik va xavfsizlik uchun `pg` Connection Pooling va indeksatsiyalangan ma'lumotlar bazasi.

3-BO'LIM // MA'LUMOTLAR BAZASI

Database Tuzilishi va Relatsiyalar

// PostgreSQL Jadvallari:

1. users (id, full_name, email, password_hash, role, is_verified, verification_code)
2. categories (id, name, slug, icon)
3. items (id, title, description, type, category_id, user_id, status, image_url)
4. claims (id, item_id, claimant_id, status, proof_description, contact_info)

🔗 Jadvallar Bog'liqligi (Relations)

• User ➔ Items (1:N): Bir foydalanuvchi bir nechta e'lonlar yaratishi mumkin.

• Items ➔ Claims (1:N): Bir e'longa bir nechta egalik da'volari tushishi mumkin.

• Category ➔ Items (1:N): Kategoriyalar orqali buyumlar tez va aniq saralanadi.

4-BO'LIM // XAVFSIZLIK

Autentifikatsiya va Email OTP Verifikatsiya

🔐

1. Registratsiya

Foydalanuvchi ma'lumotlarini kiritadi. Parol `bcryptjs` orqali xeshlanib bazaga saqlanadi.

5-BO'LIM // E'LONLAR TIZIMI

Buyumlar E'loni va Qidiruv Tizimi

📢 E'lon Turlari (Types)

• LOST (Yo'qolgan): Yo'qotilgan buyum haqida batafsil ma'lumot va mukofot miqdori.

• FOUND (Topilgan): Topib olingan buyum va uni saqlab turgan joy manzili.

🔎 Filtrlash va Qidiruv

Dinamik SQL query builder yordamida nom, kategoriya, joylashuv, sana oralig'i hamda status (`ACTIVE / RESOLVED`) bo'yicha tezkor izlash va saralash.
