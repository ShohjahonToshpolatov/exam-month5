"TOPILDI" Platformasi

Yo'qotilgan va topib olingan buyumlarni izlash va ularning egalarini topish bo'yicha zamonaviy va xavfsiz full-stack web-tizim.

⚡ Angular 19 🟢 Node.js / Express 🐘 PostgreSQL 🔒 JWT + OTP Auth ✨ 3D CSS Design
1-BO'LIM // MAQSAD

Muammo va Yechim

⚠️

Mavjud Muammo

Odamlar hujjat, kalit, hamyon yoki gadjetlarini yo'qotganda tarqoq telegram-guruhlarga murojaat qilishadi. Ma'lumotlar tez yo'qoladi, qidiruv tizimi yo'q va firibgarlik xavfi yuqori.

✅

"Topildi" Yechimi

Barcha e'lonlarni bir joyga jamlaydigan, kategoriyalarga ajratuvchi, rasm yuklash va da'vo (Claims) tizimi orqali buyum egasini aniqlaydigan yagona markazlashgan platforma.

2-BO'LIM // TEXNOLOGIYALAR

Full-Stack Texnologiyalar Steki

🔵

Frontend

Angular 19+ (Standalone Component, Signals, RxJS, Reactive Forms). Shimmer va 3D CSS animatsiyalari hamda to'liq responsive layout.

🟢

Backend API

Node.js & Express.js. RESTful API arxitekturasi, JWT middleware, Multer fayl yuklagichi va Nodemailer OTP xizmati.

🐘

Database

PostgreSQL reletsion ma'lumotlar bazasi. Yuqori tezlik va xavfsizlik uchun `pg` Connection Pool va indeksatsiyalar.

3-BO'LIM // ARXITEKTURA

Ma'lumotlar Bazasi Tuzilishi

// PostgreSQL Jadvallari:

1. users (id, full_name, email, password_hash, role, is_verified, verification_code)
2. categories (id, name, slug, icon)
3. items (id, title, description, type, category_id, user_id, status, image_url)
4. claims (id, item_id, claimant_id, status, proof_description, contact_info)

🔗 Jadvallar Relatsiyasi

• User ➔ Items: 1:N (Bir foydalanuvchi ko'plab e'lonlar berishi mumkin)

• Items ➔ Claims: 1:N (Bir e'longa bir nechta egalik da'volari tushishi mumkin)

• Category ➔ Items: 1:N (Kategoriyalash buyumlarni qidirishni tezlashtiradi)

4-BO'LIM // XAVFSIZLIK

Autentifikatsiya va Email OTP

🔐

1. Registratsiya

Foydalanuvchi parol bilan ro'yxatdan o'tadi. Parol `bcryptjs` orqali xeshlanib saqlanadi.

📩

2. Email Verification

Nodemailer orqali 6 xonali tasdiqlash kodi foydalanuvchi pochtasiga yuboriladi va akkount aktivlashtiriladi.

🔑

3. JWT Auth Guard

Login qilinganda JWT Token beriladi. Angular HTTP Interceptor barcha so'rovlarga avtomatik tokenni biriktiradi.

5-BO'LIM // XUSUSIYATLAR

Buyumlar E'loni va Qidiruv Tizimi

📢 E'lon Turlari (Types)

• LOST (Yo'qolgan): Yo'qotilgan buyum haqida ma'lumot va mukofot miqdori.

• FOUND (Topilgan): Topib olingan buyum va uni saqlab turgan joy manzili.

🔎 Filtrlash va Izlash

Dinamik SQL query builder yordamida nom, kategoriya, joylashuv, sana va status (`ACTIVE / RESOLVED`) bo'yicha lahzalik saralash va qidiruv.

6-BO'LIM // DA'VO TIZIMI

Egalik Da'vosi (Claims Workflow)

📝

Da'vo Yuborish

Foydalanuvchi buyum uniki ekanligini isbotlovchi ma'lumot (maxsus belgi, rang, serial kod) yozib da'vo yuboradi.

🔍

Egasining Tasdig'i

Buyum egasi kelgan da'voni ko'rib chiqadi va uni Approve (Qabul) yoki Reject (Rad) qiladi.

🤝

Bog'lanish

Da'vo qabul qilingach, ikkala tomon ham bir-birining telefon raqamini ko'rishi mumkin va e'lon statusi RESOLVED bo'ladi.

7-BO'LIM // MA'MURIYAT

Admin Panel va Boshqaruv

📊

Dashboard Stats

Jami e'lonlar, faol da'volar soni, registratsiyadan o'tgan foydalanuvchilarning real-vaqt statistikasi.

👥

Users Control

Foydalanuvchilar rolini o'zgartirish (User ➔ Admin), akkaunt holatini nazorat qilish.

🏷️

Categories CRUD

Yangi kategoriyalar qo'shish, ularga ikonalar biriktirish va mavjudlarini tahrirlash.

8-BO'LIM // DIZAYN

UI/UX va 3D Visual Effektlar

✨ 3D CSS Perspectives & Cubes

Landing page va Auth sahifalarida maxsus CSS `transform-style: preserve-3d` yordamida aylanuvchi 3D kublar va floating zarrachalar yaratilgan.

💎 Glassmorphism & Neon Design

Xira fon (backdrop-filter blur), gradient borderlar, interaktiv input glowing va micro-animations foydalanuvchiga zamonaviy premium taassurot beradi.
